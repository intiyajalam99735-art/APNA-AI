# Apna AI — Profile Photo + Logo Update

This ZIP includes:
- `index.html` — mobile-friendly Apna AI starter page
- `assets/apna-ai-profile.png` — profile portrait used in the page header
- `assets/apna-ai-logo.svg` — Apna AI app/site logo and favicon

## Publish on GitHub Pages
1. Open the repository `intiyajalam99735-art/APNA-AI`.
2. Upload/replace `index.html` at the repository root.
3. Upload the `assets` folder so both image files are inside `assets/`.
4. Commit the changes to the `main` branch.
5. Wait a few minutes, then refresh the website.
6. To update the Android APK, rebuild it using the live website URL after the website changes are published.

This remains a front-end demo. Real AI, OTP login, and image/video generation are not active yet.
